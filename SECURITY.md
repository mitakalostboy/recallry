# Security

v0.1.0 is an early release with no dedicated security contact or hosted reporting
channel configured yet. Do not post exploit details, credentials or private
Knowledge in a public issue.

If a future official repository offers a private vulnerability reporting option,
use that option. Otherwise, ask the maintainer to arrange a private reporting
channel without disclosing the vulnerability publicly. This document does not
claim that private reporting is currently enabled.

Provide the affected version, impact and a minimal synthetic reproduction through
the agreed private channel. Never send production databases or personal content.
